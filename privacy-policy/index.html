隱私權政策

倍榮機械工程有限公司（以下稱「本公司」）重視您的隱私權。本政策說明本公司透過 TikTok 應用程式整合服務時，如何蒐集、使用及保護相關資訊。

一、蒐集資訊之範圍

本應用程式僅用於管理本公司官方 TikTok 帳號（pmekhh），透過 TikTok API 讀取以下公開或授權範圍內之資料：

  • 帳號基本資料（帳號名稱、頭像、顯示名稱）
  • 影片成效數據（觀看次數、按讚數、留言數、分享數）
  • 帳號統計數據（粉絲數、追蹤數、影片數）

二、資訊之使用目的

上述資料僅用於本公司內部行銷成效分析與社群經營管理，不會用於其他目的。

三、資訊之保護與保存

本公司採取合理之技術與管理措施保護上述資料，僅限授權之內部行銷人員存取，並依業務需要保存，不對外揭露、販售或提供予無關第三方。

四、資料之刪除

如需刪除已授權之資料或終止授權，請聯繫下列窗口，本公司將依 TikTok 平台規範辦理。
